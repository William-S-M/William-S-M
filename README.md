## Sobre mim

Sou desenvolvedor de software com atuação em aplicações backend e web, APIs REST e microsserviços. Minha experiência inclui **integrações de sistemas no setor público**, conectando aplicações e fluxos de dados a necessidades reais de operação.

Minha stack reúne **Java com Spring Boot e Quarkus**, **Python com FastAPI** e **C# com .NET**, além de **React, Next.js e Angular** no desenvolvimento de interfaces. Também trabalho com bancos de dados e Docker na construção de soluções completas.

## Áreas de atuação

- **Backend e APIs** — desenvolvimento de serviços, regras de negócio e APIs REST para comunicação entre aplicações.
- **Microsserviços e integrações** — conexão entre sistemas e organização de serviços com responsabilidades bem definidas.
- **Setor público** — experiência com integrações que apoiam processos e a troca de informações entre sistemas.
- **Aplicações web** — construção de interfaces conectadas ao backend com React, Next.js e Angular.
- **Dados e ambientes** — persistência de dados e uso de Docker para organizar ambientes de aplicações.

Busco transformar necessidades de negócio em soluções claras, sustentáveis e úteis no dia a dia. Valorizo:
